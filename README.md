# Portfolio

Personal portfolio of Nurul Jannah Bashir Mohd. A single static page (`index.html`) with no build step.

Live site: https://nanashir1105.github.io/portfolio/

## Adding your photo

Save your photo as `photo.jpg` in the same folder as `index.html` (a portrait with the face near the centre works best, roughly 800 x 1000 px). Until it is added, the page shows your initials.
